# SkillNexis Week 4 — Full Stack Major Projects

A collection of three full-stack web applications developed as part of the SkillNexis Full Stack Development program.

## Projects

### 1. E-Commerce Web Application — ShopNexis
**Status:** Implemented and tested locally

Features:
- User registration and login
- Product listing and management
- Shopping cart
- Checkout and order placement
- Customer order history
- Admin dashboard
- Order management
- MongoDB data persistence

### 2. Social Media Feed Application — SocialConnect
**Status:** Implemented locally

Features:
- User registration and login
- Create, view, edit and delete posts
- Like and comment on posts
- User profiles
- Follow and unfollow users
- Stories
- Notifications
- Image uploads
- MongoDB data persistence

### 3. Project Management Dashboard
**Status:** In progress

Features:
- User registration and login
- Create and manage projects
- Project members and roles
- Create, edit and delete tasks
- Assign tasks to users
- Task status management
- Kanban drag-and-drop
- Image uploads and previews
- MongoDB data persistence

## Technologies Used

- Frontend: React, Vite, JavaScript, CSS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Authentication: JSON Web Tokens (JWT)
- File Uploads: Multer
